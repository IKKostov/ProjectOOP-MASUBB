ProjectOOP-MASUBB
Managing A System Used By Banks
Проект по „Увод в обектно-ориентираното програмиране" — реализация на банкова система в C++.
Функционалности

1. Управление на клиенти (регистрация, търсене)
2. Управление на сметки (разплащателна, спестовна, инвестиционна)
3. Депозит и теглене
4. Преводи между сметки
5. История на транзакциите
6. Лихвено начисляване
7. Извлечение за период
8. Блокиране и закриване на сметка
9. Известия при транзакция
10. Валутна поддръжка

Структура
src/
Account.h / Account.cpp--------->— абстрактен базов клас
CheckingAccount.h / .cpp-------->— разплащателна сметка
SavingsAccount.h / .cpp--------->— спестовна сметка
InvestmentAccount.h / .cpp------>— инвестиционна сметка
Client.h / Client.cpp----------->— клиент на банката
Transaction.h / Transaction.cpp->— транзакции
main.cpp------------------------>— главно меню
